# Tinker Pack — Sprites

**Paired preset:** `tinkerer`
**License:** MIT
**Author:** Ensemble built-in

## Aesthetic

The Tinker pack channels the workshop bench: half-soldered circuits, CRT glows, and the satisfying click of physical interaction. Every sprite is drawn on a consistent 100×100 grid with `currentColor` fills so they adapt cleanly to any dashboard theme. The palette is monochromatic with accent highlights—technical, precise, and a little luminous.

## Items

| ID | File | Description |
|----|------|-------------|
| `terminal` | `terminal.svg` | Terminal window with prompt and blinking cursor |
| `blueprint-grid` | `blueprint-grid.svg` | Engineering blueprint grid with center crosshair |
| `oscilloscope` | `oscilloscope.svg` | CRT oscilloscope with sine wave trace |
| `solder-iron` | `solder-iron.svg` | Soldering iron with heat glow at tip |
| `circuit-trace` | `circuit-trace.svg` | PCB routing traces with vias and pads |
