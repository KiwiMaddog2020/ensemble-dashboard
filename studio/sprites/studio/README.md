## Aesthetic

The Studio pack is built from the analog signal chain: potentiometers, tape formulations, and the warm geometry of vintage gear. Each sprite is drawn with mechanical precision—tick marks, ring grooves, connector threads—details that reward a close look. The color system maps naturally to console-era finishes.
