CHEATSHEET — The Ensemble

Quick reference. Open this when you need a signal phrase, a file path, or a play-button command. For deep-dive, see the onboarding design or research/.

Signal phrases (exact verbatim)

Phrase Who says it What it does
***INITIATING AUTOPILOT*** Agent or Maestro Announces they’re about to take the wheel. Always the LAST line of that turn. You approve to proceed.
***AUTOPILOT COMPLETE*** The chat that held autopilot Lock released. Work done.
***ORCHESTRATOR OFF*** You Kill-switch. Any chat that sees this verbatim executes the six-phase cascade. Releases lock, pauses automations, flips mode to direct.
***ORCHESTRATOR ON*** You Resume. Clears cascade tombstone, flips mode to orchestrated.
⏸ ORCHESTRATOR IN TRANSITION — standing by. Any chat Someone else is running the cascade; this chat waits.
[<slug>:<task> AUTOMATION FIRE] First output line of any scheduled task Makes automation events instantly identifiable in logs.

Turbo session (60-min autonomous chat)

Paste this into any onboarded Agent or Virtuoso chat to run a 60-minute autonomous work session that picks up new tasks when current ones finish early, then audits everything at the end:

cat ~/.claude/orchestrator/plugins/ensemble/templates/turbo_session.txt
# copy the full output between BEGIN/END markers and paste into the chat

What it does: 1. Reads operating contract + charter + memory files 2. Acquires per-project spawn lock (Layer 2 of three-layer mutex) 3. Loops Plan→Code→Test→Fix→Wrap on top_recommendation, then alternatives, then charter priorities 4. At T+55min: stops new tasks, finalizes 5. At T+60min: writes comprehensive audit (per-task summary, quality check, open questions, next-session recs) to runs/turbo-<slug>-<stamp>.md 6. Releases lock, prints tight summary, stops

Adjust budget by editing SESSION_BUDGET_MINUTES at the top of the prompt before pasting (default 60).

User AFKs the entire time. Chat doesn’t ask questions during autonomous phase. Safety gates (public-flip, billing, account creation) still fire if encountered.

Common commands (play-button)

System health at a glance

${CLAUDE_PLUGIN_ROOT}/bin/status.sh

List active scheduled tasks

ls ~/.claude/scheduled-tasks/ 2>/dev/null && echo "--- and launchctl ---" && launchctl list | grep -E 'orchestrator|ensemble'

Three-layer mutex status

${CLAUDE_PLUGIN_ROOT}/plugins/ensemble/bin/orchestrator_spawn_lock.sh status

Sweep stale spawn locks

${CLAUDE_PLUGIN_ROOT}/plugins/ensemble/bin/orchestrator_spawn_lock.sh sweep

Run the v2.0 race test (9-test mutex suite)

${CLAUDE_PLUGIN_ROOT}/plugins/ensemble/bin/test_spawn_lock_race.sh

Sync lint configs to all 5 companion repos

${CLAUDE_PLUGIN_ROOT}/plugins/ensemble/bin/sync-lint-configs.sh

SwiftBar menu bar — install one-shot

bash ${CLAUDE_PLUGIN_ROOT}/plugins/ensemble/integrations/swiftbar/setup.sh

Inspect current state

jq . ${CLAUDE_PLUGIN_DATA}/state.json

Who holds the autopilot lock (if any)?

[[ -d ${CLAUDE_PLUGIN_DATA}/state.lock.d ]] && jq . ${CLAUDE_PLUGIN_DATA}/state.lock.d/holder.json || echo "lock is free"

Force-release the lock (emergency only; normally the cascade handles this)

rm -rf ${CLAUDE_PLUGIN_DATA}/state.lock.d && jq '.active_autopilot_chat=null | .active_vm=null | .lock_acquired_at=null' ${CLAUDE_PLUGIN_DATA}/state.json > /tmp/s.json && mv /tmp/s.json ${CLAUDE_PLUGIN_DATA}/state.json && echo "lock force-released"

Recent steal log (post-mortem)

tail -30 ${CLAUDE_PLUGIN_DATA}/lock_steals.log 2>/dev/null || echo "no steals yet"

Today’s morning briefing

cat ${CLAUDE_PLUGIN_DATA}/briefings/$(date -u +%Y-%m-%d).md 2>/dev/null || echo "no briefing yet"

Roster of onboarded Agents

for f in ${CLAUDE_PLUGIN_DATA}/chats/*.json; do
  jq -r '"\(.chat_id) — \(.status) — \(.top_recommendation.title // "no rec")"' "$f" 2>/dev/null
done

Pull latest orchestrator updates

${CLAUDE_PLUGIN_ROOT}/bin/upgrade.sh

Run the concurrency test on the lock

${CLAUDE_PLUGIN_ROOT}/bin/test_lock_race.sh

Reload the stale-lock sweeper

launchctl unload ${CLAUDE_PLUGIN_ROOT}/launchd/com.kevin.orchestrator.stale-lock-sweeper.plist 2>/dev/null; launchctl load ${CLAUDE_PLUGIN_ROOT}/launchd/com.kevin.orchestrator.stale-lock-sweeper.plist && echo "sweeper reloaded"

Tail sweeper logs

tail -f /tmp/orchestrator-sweeper.out

Quick troubleshooting

Symptom Fast check Deeper
Tools blocked with ORCHESTRATION LOCK: message Correct — the hook is working. Read the message. TROUBLESHOOTING § 2
[ORCHESTRATOR] … MISSING at session start Hook not registered. Check ~/.claude/settings.json. TROUBLESHOOTING § 3
Routine didn’t fire overnight Desktop app closed or Mac asleep. Check “Keep computer awake” + don’t close lid. TROUBLESHOOTING § 6
Autopilot lock stuck Wait 45 min for sweeper, or force-release (above). TROUBLESHOOTING § 4
state.json broken Restore from *.backup.* or re-init from schema. TROUBLESHOOTING § 7

Mode quick-reference

state.json.mode Behavior
orchestrated Full protocol. Hooks enforce. Routines fire.
direct Conversational only. No rapid-fire format. Hooks block all VM tools. Routines no-op.
mode_transitioning: true Shutdown cascade in flight. New autopilot blocked.

To flip: say ***ORCHESTRATOR OFF*** or ***ORCHESTRATOR ON*** verbatim on its own line to any chat.
