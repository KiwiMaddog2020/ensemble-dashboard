Repo README

Top-level claude-ensemble README — concepts, install, repo layout.

source: README.md

Claude Code marketplace hosting the Ensemble plugin. One chat conducts many — multi-chat orchestration with shared state, rapid-fire decisions, a three-layer autopilot mutex, and a global kill-switch. Built for users running several Claude Code sessions at once on the same machine.

Install

/plugin marketplace add KiwiMaddog2020/claude-ensemble
/plugin install ensemble@claude-ensemble
/exit   # so the SessionStart hook attaches next time you open a chat

Open a fresh chat. You should see [ORCHESTRATOR] hard-enforcement active at the top of context. Then:

/ensemble:maestro           # in any new chat → becomes your orchestrator
/ensemble:agent-onboard     # in a project repo → onboard the chat as an Agent

Full install walkthrough: docs/INSTALL.md.

Core concepts

  • Maestro — one chat, one baton. Coordinates, ranks top recs across projects, never holds the autopilot mutex.
  • Agents — scoped to one repo each. Read a per-project charter, report status in rapid-fire format, acquire the autopilot mutex before firing work.
  • Three-layer autopilot mutex — workshop lock (computer-control) + per-project spawn lock (file-stomp prevention) + resource floor (opt-in RAM/CPU pre-check), with a user-controlled max_concurrent_autopilots cap (default 2). Cap-hit = queue with 5-min timeout.
  • Six-state lifecycle — every project moves through Building → Launch Prep → Warmer ⇄ R&D ⇄ Updates → Hibernating. Auto-transitions at G1/G7/G8.
  • Kill-switch — say ***ORCHESTRATOR OFF*** in any chat. Six-phase cascade releases all locks, pauses automations, flips mode to direct. Any chat can execute; protocol handles races.

More detail on each piece: plugins/ensemble/README.md.

Eight new operating directives, baked into MAESTRO.md + AGENT.md:

# Directive One-line
1 Smart handoff Self-monitor context: 80% warn → 90% stage → 95% hard-stop with paste-ready resume prompt
2 Turbo mode Liberal turbo signal triggers AFK batch coding; safety gates still fire
3 Outside-the-box thinking Priority 1 operating posture; build calibration tools when warranted
4 Feedback pipeline Sunday 6am aggregator + plan-then-approve gate for live products
5 Six-state taxonomy Replaces evolution_modes; bidirectional live triangle
6 State enable/disable Verbal + PWA; set <slug> to <state>
7 Three-layer mutex Workshop + per-project spawn + opt-in resource floor; user-controlled cap
8 Rapid-fire toggle Per-chat toggle; every AskUserQuestion call reserves slot 4 for “Disable Rapid Fire Mode” escape hatch

Plus Tier 1 hardening: caffeinate -i wrap (anti-sleep), battery awareness, disk pre-flight, log rotation. SwiftBar menu bar indicator with one-shot installer. Lint discipline baked into CI (markdownlint / yamllint / ruff / prettier / EditorConfig).
