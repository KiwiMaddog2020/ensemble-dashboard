plugins/ensemble/PHONE_QUICKSTART.md

Phone Quickstart — trigger Ensemble autopilot from your iPhone

AirDrop this file to your phone, open in Files → Markdown, follow the steps below. Target time to complete: ~15 minutes. Once done, you have 6 home-screen icons on your phone that fire different actions against your Mac.

0. What you’ll have when done

Six home-screen icons on your phone:

  • 🔥 Autopilot 15m — fire a 15-minute coding session
  • 🔥 Autopilot 30m — fire a 30-minute session
  • 🔥 Autopilot 60m — fire a 60-minute session
  • 🔥 Autopilot 120m — fire a 2-hour session
  • ❌ Ensemble Kill — stop everything
  • ℹ️ Ensemble Status — see what’s running

Tap any of them from anywhere with cell signal. The Mac doesn’t need to be on the same WiFi; Tailscale handles the connection over cellular.

1. Mac-side setup — AUTOMATED

One command does everything on the Mac side. Open Terminal on your Mac and run:

bash ~/.claude/orchestrator/bin/setup-mobile-dispatch.sh

This script handles every step below automatically (idempotent — safe to re-run):

  • ✓ Installs Tailscale via Homebrew
  • ✓ Launches Tailscale.app for sign-in (you sign in once)
  • ✓ Enables Remote Login (opens System Settings if macOS privilege-gates the CLI)
  • ✓ Disables Mac sleep on AC power via pmset
  • ✓ Generates an ed25519 SSH keypair at ~/.ssh/ensemble_phone
  • ✓ Appends the pubkey to ~/.ssh/authorized_keys (deduped)
  • ✓ Loopback-tests SSH + mobile_dispatch.sh status
  • ✓ Copies the private key to your Mac clipboard (Universal Clipboard syncs to phone)
  • ✓ Prints every value you need for the Shortcuts — Tailscale IP, username, each script to paste

Time: ~2 minutes (plus the one-time Tailscale sign-in in a browser).

At the end, the script prints a copy-pasteable summary with all values. Skip straight to §2 for phone-side setup.

Manual fallback (only if the automated setup fails)

Click to expand the manual Mac-side steps #### 1a. Install Tailscale 
brew install --cask tailscale && open -a Tailscale
Sign in, click "Install system extension" if prompted. Note your Mac's Tailscale IP (e.g. `100.64.0.12`) — shown in the Tailscale menu-bar icon's "My devices" entry. #### 1b. Enable Remote Login **System Settings → General → Sharing → Remote Login: ON.** Under "Allow access for," add your user. Run `whoami` in Terminal; note the username. #### 1c. Prevent sleep on AC 
sudo pmset -c sleep 0 displaysleep 10 disksleep 0
#### 1d. Generate the phone's SSH key 
ssh-keygen -t ed25519 -f ~/.ssh/ensemble_phone -N "" -C "ensemble-phone-$(hostname)"
cat ~/.ssh/ensemble_phone.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
pbcopy < ~/.ssh/ensemble_phone
#### 1e. Verify scripts 
bash ~/.claude/orchestrator/bin/mobile_dispatch.sh status

2. Phone-side setup (10 min, on your iPhone)

2a. Install Tailscale on the phone

App Store → Tailscale → install → sign in with the same account as your Mac. Grant VPN permission. Confirm Mac appears in device list with a green dot.

2b. Save your SSH key in Notes (temporarily)

  • On your Mac, you just ran pbcopy < ~/.ssh/ensemble_phone. Your clipboard holds the key.
  • AirDrop that note to the phone, OR: Messages → send the key to yourself → copy from your own thread on phone. (iCloud sync of clipboard across Mac + iPhone also works if you have Universal Clipboard enabled.)
  • On the phone, open Notes → new note → paste. Title it “ensemble key (temp)”. You’ll delete this after step 2d.

2c. Build Shortcut “Autopilot 30m” (template for the others)

  1. Open Shortcuts app on phone → + (top right).
  2. Rename to Autopilot 30m (tap the title to rename).
  3. Tap the icon to pick a color + symbol (flame is fitting).
  4. Tap + Add Action → search Run Script Over SSH → select it.
  5. Fill the action: - Host: your Mac’s Tailscale IP (from step 1a) - Port: 22 - User: your Mac username (from step 1b) - Authentication: tap → SSH Key → Choose Key → Create New SSH Key
    • Name: ensemble_phone
    • Type: ed25519
    • After creation, tap “Use as input” is NOT what you want — instead tap Share Public Key, AirDrop it back to your Mac, then on Mac: bash cat ~/Downloads/*.pub >> ~/.ssh/authorized_keys
    • Delete the .pub file from Mac Downloads when done.
    • Input: leave as Shortcut Input
    • Script: bash ~/.claude/orchestrator/bin/mobile_dispatch.sh fire 30
  6. Add a second action: + Add Action → search Show Notification. - Title: Ensemble - Body: tap and select Shell Script Result (the output of step 5)
  7. Tap Done (top right).
  8. Back at the shortcut tile, tap ⋯ → Add to Home Screen. Name + icon color as desired. Add.

2d. Duplicate for 15 / 60 / 120 variants

  1. Long-press Autopilot 30m in Shortcuts → Duplicate.
  2. Rename the copy → Autopilot 15m. Tap into it, change the script’s last number from 30 to 15. Add to home screen.
  3. Repeat for 60 and 120. Four Autopilot shortcuts total.

2e. Build “Ensemble Kill” shortcut

  1. New Shortcut → Ensemble Kill, red icon, stop-sign symbol.
  2. Run Script Over SSH (same host/user/key). Script: bash ~/.claude/orchestrator/bin/mobile_dispatch.sh kill.
  3. Show Notification with Shell Script Result.
  4. Add to Home Screen. Place this one in an easy-to-reach spot — panic button.

2f. Build “Ensemble Status” shortcut

  1. New Shortcut → Ensemble Status, info-icon.
  2. Run Script Over SSH. Script: bash ~/.claude/orchestrator/bin/mobile_dispatch.sh status.
  3. Show Notification (or better: use Show Result action for a longer text view).
  4. Add to Home Screen.

2g. Clean up

  • Delete the “ensemble key (temp)” note from Notes.
  • Delete any Messages you sent to yourself with the key content.
  • The key now lives only in (a) ~/.ssh/ on your Mac, (b) the iOS Shortcut itself (encrypted by iOS).

3. Test sequence (2 min)

From the phone, in this order:

  1. Tap Ensemble Status. Expect a notification showing mode: orchestrated, lock: free, some counts. If you see connection errors, see Troubleshooting below.
  2. Tap Autopilot 15m. Within 3 seconds you should see: - On phone: notification OK fire acknowledged: 15 minutes (pid N) at <timestamp> - On Mac: a “Ensemble” notification in the corner saying autopilot fired
  3. Within 15–17 minutes (duration + 2-min cleanup buffer), a second Mac notification fires: Autopilot <stamp> done (exit 0, budget 15m). On the Mac, check the run log: bash ls -lat ~/.claude/orchestrator/runs/autopilot-*.md | head -3 cat ~/.claude/orchestrator/runs/$(ls -t ~/.claude/orchestrator/runs/autopilot-*.md | head -1 | xargs basename)
  4. Tap Ensemble Kill. Notification confirms. Any in-flight autopilot sessions are killed; kill_signal.txt is dropped so the Maestro can run its shutdown cascade on next turn.

4. Troubleshooting

“Could not connect to host”: - Tailscale green on both? Open Tailscale app on phone — Mac should have a green dot. - Mac awake? caffeinate -d -i -s & in Terminal for a force-stay-awake session. - Remote Login on? System Settings → Sharing → Remote Login must be ON. - Firewall? sudo /usr/libexec/ApplicationFirewall/socketfilterfw --listapps | grep ssh — sshd should be allowed.

“Permission denied (publickey)”: - Key not registered on Mac? Run: grep ensemble-phone ~/.ssh/authorized_keys — should show the pub key line. If not, follow step 2c sub-step again. - .ssh permissions wrong? chmod 700 ~/.ssh; chmod 600 ~/.ssh/authorized_keys

Shell returns empty: - In the Shortcut, tap ⋯ on the “Run Script Over SSH” action → Show When Run. Next run will show raw output for debugging.

Autopilot fires but no run log appears: - Check ~/.claude/orchestrator/mobile_dispatch.log — should show spawned autopilot_session.sh <N> with a pid. - Check ~/.claude/orchestrator/runs/autopilot-*.raw.log — raw stdout/stderr of the claude -p session. May show why it aborted. - Most common: mode != orchestrated or lock already held. The session refuses gracefully and logs the reason.

Mac Notifications not showing on phone: - System Settings → Notifications → Phone → ON for iMessage forwarding. Or switch to Pushover for explicit push (free tier, 10-minute setup).

5. Daily use

  • At work, need an autopilot run: tap 30m/60m/120m. Go back to work. Check the run log later.
  • Autopilot wandering: tap Kill. Review the log; adjust the charter if it picked a bad task.
  • Status check: tap Ensemble Status. One tap, one line of output.

The Mac side is deterministic — mobile_dispatch.sh logs every call to ~/.claude/orchestrator/mobile_dispatch.log. That’s the audit trail if anything looks wrong.
