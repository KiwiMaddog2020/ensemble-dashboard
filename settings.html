Suite Library beta

A Suite bundles your whole vibe-coding setup — CLAUDE.md, Claude skills, themes, provider mix, Canvas layout, agentic-OS config, and more — into one installable package. Publish yours so other makers can install it; install theirs so their rig lands on your machine.

Connect a runner to publish Suites. Hosted settings stay available here; Suite publishing still runs through your paired Mac. Pair this browser →
What’s included in every Suite
  • CLAUDE.md — standing-instructions context the installer’s Claude loads on every chat.
  • Claude skills — installable skill definitions + per-skill config (the SKILL.md files plus assets).
  • MD files — supplementary docs / glossaries / decision logs.
  • Provider mix — BYOK preferences (which providers, model defaults, fallback ladder). Keys stay BYOK; only the preference shape travels.
  • Canvas layout — published rooms visitors walk through.
  • Appearance — theme (one of the 21-theme spectrum) + custom background.
  • Agentic-OS config — Terminal column widths, Dashboard widget order, Maestro/Council persona prefs.
  • Brand identity — logo, accent overrides, palette.
  • House rules — custom prompts + standing instructions Claude follows in the installer’s environment.
  • Autopilot defaults — per-project cap, mode, work-hours window.
  • Sprite packs + backgrounds (opt-in) — custom sprite packs + custom backgrounds. Installer is warned + given an install/skip choice.

Exports as a self-contained .claude/endenza/ directory you can drop into any working repo — that repo inherits the Suite the moment a Claude Code chat opens in it. See the portable-format spec →
